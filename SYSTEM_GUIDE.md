```

ALPACA_API_SECRET=your_secret
ALPACA_API_BASE_URL=https://paper-api.alpaca.markets/v2
ALPACA_ENVIRONMENT=paper
ANTHROPIC_API_KEY=sk-ant-your_key_here
```

Get an API key at https://console.anthropic.com/settings/keys. The `CLAUDE_MODEL` line is optional — defaults to `claude-sonnet-4-6`. Other valid options: `claude-opus-4-7` (smarter, ~5x more expensive) or `claude-haiku-4-5` (faster, cheaper).

## ⚠️ Risk Management Rules

### Position Sizing
- **Max per trade:** 2% account risk (stop loss)
- **Max per position:** 5% of account
- **Max portfolio heat:** 5% total at risk

### Stop Losses
- Every trade must have a stop loss
- Suggested: 0.3-0.5% of account per trade
- Enforce via trade journal + manual review

### Drawdown Limits
- **Max drawdown alert:** 10%
- **Warning level:** 5%
- If exceeded: Reduce position size, review strategy

### Weekly Targets
- **Goal:** +1.0% per week
- **Acceptable:** 4-5 weeks out of 6 hitting target (70% confidence)
- **OK to have:** Flat weeks or small losses (30% of time)

## 📊 Example Trade Decision Tree

```
1. Claude suggests AAPL at $180 with $175 stop loss
2. Calculate position size:
   - Risk = 180 - 175 = $5 per share
   - Max loss allowed = account * 2% = $2,000
   - Shares = $2,000 / $5 = 400 shares
   - Position value = 400 * 180 = $72,000
   - Position % = $72,000 / $3,600,000 = 2%  ✅

3. Log entry:
   python trade_journal.py entry AAPL 400 180.00 175.00 182.00 "Claude signal" claude

4. Monitor daily with:
   python portfolio_monitor.py check

5. When exiting (at $182 target):
   python trade_journal.py exit 1 182.00 target_hit
```

## 🚨 Alert System

### Alerts That Trigger
- **HIGH_HEAT:** Portfolio heat > 8%
- **ELEVATED_HEAT:** Portfolio heat 5-8%
- **MAX_DRAWDOWN:** Drawdown > 10%
- **LOSING_STREAK:** 3 consecutive losses
- **LOW_CASH:** Cash < 10% of account
- **WEEKLY_LOSS:** Down 2%+ this week

- Verify model name matches one of the current model IDs

- Alpaca free tier has limited data access
- Use backtesting with saved historical data
